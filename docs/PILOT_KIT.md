# TeacherLens 教师试点交付包 · v0.6

## 试点目标
验证“教师评价意图校准是否有增量价值”，而不是预设结论。适用初中语文阅读日常作业，非正式考试。仅在校方与教师授权的环境处理匿名转写；公开演示仅限模拟样本。

## 现场任务（约30分钟，计划值）
1. 请老师展示已有评分细则、批改工作流，记录痛点和既有替代方案。
2. 让老师独立评阅8–10个边界答案并说明理由，不先展示AI。
3. 使用演示工作台：选择边界判断→运行初评→筛选复核→确认/修改并导出。
4. 对照评测实验室区分改善、退化和仍有差异，记录是否信任、哪些操作增加负担。
5. 讨论下一次作业是否愿意复用规则。未实际试用不得声称有需求或提效。

## 试点验收（拟定，须教师确认）
评分质量：同分一致率不低于量规基线，严重分差比例不增加；净人工时间减少20%为探索目标，计入准备、校准、复核和修改。重复使用另用新题测试，禁止校准与测试集重叠。记录人工实际耗时、复核率、修改率、未评分比例。任何异常都不得自动发布分数。

## 访谈记录与产品优化
使用 interview-template.csv（模板无实际访谈数据）；区分原话、观察、推测。使用 issue-template.csv 记录问题、证据、发生频次、严重度、影响、方案与验收标准。优先按影响及证据而非功能数量排序。

## 部署及复制
公开Render：无密钥，固定模拟任务。真实POC：经批准的本地环境或校方授权平台，另行设计数据权限、留存与删除。千问办公：下载Skill说明，按仓库完整技能目录及客户端规范尝试安装；当前未实测。钉钉家校本：尚未集成。教研组规范与教师偏好冲突时，以适用正式规范为准；不固化未经验证的个人习惯。
