# 教育解决方案 POC 任务书（待执行）
目标：确认教师评价标准是否需要适配；在质量不降低的前提下验证净人工耗时。

## 用户调研
邀请 3–5 位初中语文教师。先观察最近一次批改的实际工作方式，问：哪些答案最难判？评分细则在哪里？同题不同教师为何有分歧？试过什么 AI？为什么继续或放弃？批完之后如何讲评？让教师独立评分同一批 8–10 个模拟或授权匿名答案，追问分歧原因。不要暗示产品结论。

## 测试
选 1–3 位教师，30–60 份匿名作答；校准样本、同题独立测试样本、新题迁移样本严格分离。用同一模型版本、同一输入比较 A 参考答案、B 明确量规、C 量规+校准。三组独立运行；教师预先独立标注或共同确认评价标准，不使用 AI 输出反向构造金标。记录模型、规则版本、重复次数及运行条件。对耗时实验随机化/平衡顺序，降低记忆和熟练度影响。

指标：同分一致率、MAE、有效评分覆盖率、全量正确率、严重分差比例（≥2分）、复核率、教师修改率、净人工时间（包括准备、扫描、设置、校准、核验和修改）。不把教师个体意见当作普遍事实。初步成功门槛（拟定）：净人工时间降低20%，同分一致率不低于明确量规基线，严重错误不增加；需与教师共同确认。

## 反馈记录模板
访谈编号｜任务｜原话/观察｜证据｜痛点｜频率/影响｜当前替代方法｜方案｜优先级｜待验证事项

Badcase ID｜样本ID｜原作答｜AI结果｜参考评分｜规则版本｜证据｜疑似原因｜负责人｜状态｜修复验证

## 边界
没有真实教师试用、校方授权、千问办公客户端验证之前，不得声称项目已上线、实际节省时间或已覆盖真实学生。真实数据不进公开 GitHub；采用学校许可的环境，去标识化，设定留存及删除机制。正式考试不自动发布。教师评分争议按适用规范复核。
