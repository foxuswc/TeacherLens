# TeacherLens v0.8 交互升级
- 任务入口：仅展示真实可运行的模拟任务及实时会话进度，不编造学校任务或活动记录。
- 教师流程：作业材料与量规 → 两个边界案例 → 运行初评 → 逐份三栏复核。返回校准后重新运行需明确确认清除已有确认记录。
- 评阅页：原作答与量规、分项证据和定位、教师分数和评语、修改原因、反馈分类、下一份、复核筛选、导出 JSON。教师评语仅随浏览器会话导出，非后端持久化。
- 评测页：同源固定样本的三种策略、四项独立刻度图、逐样本差异；所有统计由现有评测接口返回。
- 行业方案：试点任务书、Skill、访谈及问题台账可下载。尚未开展真实试点。
- 设计参考：淡紫白、书本插画、统一顶栏、有限信息密度。移动端单列布局。
- 验收：检查首页→规则→校准→初评→证据定位→调整分数→保存→筛选→导出→评测→方案下载；刷新清空会话；公开版禁止模型调用。自动化浏览器测试尚待执行。
